## 1. 变更了什么

翻面前（L27 起）：`/api` 的 GET **匿名可读**（只读面公开），只有写方法（POST/PUT/DELETE/PATCH）
要 `X-Admin-Token`。翻面后：**`/api/**` 与 `/console**` 的所有方法（含 GET）都要
"旧令牌或会话"二选一**；匿名请求一律 `401` + 业务码 `7002`（响应体形状不变）。

不变的部分：

- C 端业务写口照旧匿名（`/api/coupons/receive|receive-async|lock|confirm|release|refund`）——
  它们的防线是风控闸/幂等/状态机，不是管理令牌；`/open/v1/**` 签名链完全不受影响；
- `/console/api/auth/**`（登录/登出/me）照旧匿名可达（登录自举的前提）；
- `/actuator/health`、`/actuator/info` 照旧匿名（K8s 探活）；
- 写接口的令牌要求、恒定时间比对、令牌未配置 fail-closed 全部原样。

**同批的第二处收窄**：`/actuator/prometheus` 从匿名面移入凭据面——
现在和 `/actuator/metrics` 一样要 `ROLE_ACTUATOR` + Basic
（匿名面只剩 `health`、`health/**`、`info`）。

## 2. 影响面（谁会开始收到 401）

| 调用方 | 症状 | 处置 |
|---|---|---|
| 匿名 `GET /api/**` 的脚本/巡检（如读 `/api/switches/breakers`） | 401 + 7002 | 请求头补 `X-Admin-Token`（仓库内脚本已同批更新：`scripts/open-api/lib.sh` 的 `breaker_state`、`drill.sh` 提示文本与 prometheus 抓取、`scripts/cluster/verify-cluster.sh`、`scripts/cluster/lib-gate-repair.sh` 的 prometheus 抓取——后四处经审查补齐，均读 `ACTUATOR_AUTH` 环境变量，默认 dev 凭据） |
| 运营/对账人员直连内部面读数 | 401 | 改走控制台会话（`/console/api/auth/login`），或请求带 `X-Admin-Token` |
| Prometheus 抓取器 | `GET /actuator/prometheus` 401 | 见 §4 配 Basic 凭据 |
| C 端业务口（receive/lock 等）、`/open` 签名调用、K8s 探针 | **不受影响** | 无 |

## 3. 旧管理令牌（X-Admin-Token）退役计时

令牌路径**本刀不删**，但进入退役倒计时：

- 每次旧令牌命中会计数 `admin_legacy_token_usage_total`（Micrometer 名
  `admin.legacy.token.usage`；启动即注册，从未用过 = 0）；
- 每个进程首次命中打一条 WARN：`ADMIN LEGACY TOKEN IN USE: 旧管理令牌仍在使用——
  将在一个发布周期后移除，迁移到 /console/api/auth 会话登录`；
- **迁移路径**：人的调用走控制台会话（登录 `/console/api/auth/login`，会话空闲 30 分钟/
  绝对 8 小时，权限即时生效）；机器脚本短期继续用令牌，等 RBAC 的 PAT（个人访问令牌）
  就位后切换；
- **删除判据**：一个完整发布周期内 `admin_legacy_token_usage_total` 增量归零
  （PromQL：`increase(admin_legacy_token_usage_total[7d]) == 0`）→ 下个发布周期删除
  令牌路径与 `BUSINESS_WRITE_PATHS` 之外的全部旧判据。

## 4. Prometheus 抓取器迁移（必做，否则抓取断流）

1. 给服务配凭据（环境变量）：
   `ACTUATOR_AUTH_USER=actuator`、`ACTUATOR_AUTH_PASSWORD=<强随机值>`；
   （不配则凭据随机生成，等价于 prometheus/metrics 不可达——fail-safe。）
2. 抓取任务加 Basic 头：
   ```yaml
   scrape_configs:
     - job_name: newcoupon
       basic_auth: { username: actuator, password: '<同上>' }
       metrics_path: /actuator/prometheus
   ```
3. 验证：`curl -u actuator:<密码> http://<host>/actuator/prometheus | head`；
   匿名 `curl -i` 应得 401（这是预期，不是故障）。

## 5. 回滚（发布保险，一个发布周期后删）

翻面出了问题（某个未登记住的匿名调用方被打断且来不及改）时：

```
API_READ_AUTH_ENABLED=false        # 环境变量方式
# 或配置文件方式：coupon.security.api-read-auth-enabled: false
```

- `false` = 恢复 2A-1 语义：只有写方法要令牌，**GET 恢复匿名放行**（写接口要求不变）；
- 回滚**只**回滚 /api 读面翻面；prometheus 的 Basic 要求不随之回滚（抓取器按 §4 迁移后
  不需要退回匿名）；
- 该开关是过渡件：旧令牌删除的那一刀会连它一起删，不要当长期功能用。
