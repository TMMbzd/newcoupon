# 六阶段实施路线总览

**总工期**: 20-27 天（约 3-4 周）  
**开始日期**: 2026-10-09  
**预计完成**: 2026-10-30 ~ 2026-11-05

---

## 一、六阶段全景图

```
Phase 1: 核心业务闭环（5-7天）⭐ 最关键
  ↓ 补齐优惠计算引擎，形成端到端闭环

  ↓ 活动配置、批量发放、人群包

  ↓ 接入文档、运维手册、教学材料
```

## 三、关键路径与依赖关系

### 3.1 串行依赖

```
Phase 1（优惠计算）必须先完成
  ↓ 才能做
Phase 2（运营管理：活动依赖计算引擎）
  ↓
Phase 3（前端：依赖后端接口）
  ↓
Phase 4（高级能力：依赖基础能力）
  ↓
Phase 5（生产就绪：依赖完整功能）
  ↓
Phase 6（文档：依赖所有功能）
```

### 3.2 可并行部分

**Phase 3 + Phase 4 可部分并行**（需要 2 人）:
- Person A: 前端开发（Phase 3）
- Person B: 高级能力开发（Phase 4 高级部分）

**收益**: 总工期缩短 3-4 天（20-27 天 → 17-23 天）

**前提**: 用户有前端开发能力或团队协作

## 五、资源需求

### 5.1 人力

**单人模式**（推荐）:
- 1 人全栈开发
- 总工期 20-27 天

**双人模式**（可选）:
- Person A: 后端 + 部分前端
- Person B: 前端主力
- 总工期 17-23 天（Phase 3/4 并行）

### 5.2 环境

**开发环境**:
- JDK 17
- Maven 3.8+
- Docker Desktop（MySQL/Redis/RocketMQ/XXL-Job）
- Node.js 18+（前端）
- IDE（IntelliJ IDEA / VS Code）

**测试环境**:
- WSL2 或 Linux（~6.6G 内存）
- Testcontainers（自动）

**生产环境**（Phase 5）:
- K8s 或 Docker Compose
- Prometheus + Grafana
- Nginx

## 六、风险管理

### 6.1 高风险项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| **Phase 1 超期** | 后续全部延期 | 严格控制范围，异步模式可降级 |
| **前端开发能力不足** | Phase 3 卡住 | 使用 Ant Design Pro 脚手架，降低难度 |
| **WSL2 资源不足** | 测试失败 | 重活串行，跑测试前停应用 |

### 6.2 中风险项

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| V15 迁移破坏测试 | Phase 1 延期 | 迁移后立即跑全量测试 |
| 动态规划算法复杂 | Phase 4 延期 | 先实现简单贪心，Phase 6 优化 |
| 监控配置繁琐 | Phase 5 延期 | 使用预制配置模板 |
