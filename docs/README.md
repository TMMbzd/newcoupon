## 核心设计一句话

**用 Redis+Lua 把五重校验压成一次原子操作，用"Redis 可扣 ≤ DB 已推送 ≤ DB 审批总量"不变式锁死超发，用状态机条件 UPDATE + 占用单幂等锚点管住券的一生，用事件明细做唯一事实源，用对账把所有假设变成可验证的事实。**
