# ADR-0001: 阶段 0 采用单体 + 单库 + 零中间件

- **状态**：已接受（2026-09-03）
- **背景**：设计文档集（docs/）已完成到 DDL/Lua/时序级。启动实现时面临选择：直接按最终形态（v3：Redis+Lua+分库分表+MQ）搭建，还是从最朴素的 v1 开始分阶段演进。
- **决策**：阶段 0 = Spring Boot 单体 + 单库 MySQL + 无 Redis/MQ/分库分表。扣库存用模板行条件更新，限领 1 张用唯一索引强制，过期用任务表轮询。
- **理由**：
  1. 18 篇素材的演进史（京东到家/vivo/字节）全部从单体长出来——v1→v3 的每一版演进都是"先感受到痛，再设计解药"；
  2. 直接从 v3 起步学不到东西（不知道 Redis+Lua 在防什么），先在压测里亲手看到行锁排队、超发，阶段 1 的设计才会真正被理解；
  3. 阿里规约：禁止超前设计——没有痛点的架构是负资产。
- **后果**：
  - 正面：一周内可运行、可压测、可验收；每引入一个中间件都有真实痛点驱动。
  - 负面（明确接受）：单模板并发扣减上限约几百 QPS（行锁）；每人限领仅支持 1 张；这些在阶段 1/2 解决。
- **退出条件**：阶段 0 验收通过（1000 并发抢 100 张零超发 / 幂等 / 回退幂等）后进入阶段 1（引入 Redis）。
